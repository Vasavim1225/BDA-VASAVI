Education Fees Analytics Dashboard
An interactive Power BI dashboard developed to analyze educational fee collection, course-wise revenue, monthly enrollment, and student demographics.

Key Features
Total Fees: ₹6.939M
Total Records: 772
Course Analysis: Compares fees across 8 courses.
Monthly Analysis: Tracks enrollment from January–December.
Age Analysis: Visualizes student distribution across age groups.
Filters: Year, Course, and City for interactive analysis.

Tools Used
Power BI | Power Query | DAX | Excel | Data Visualization

Objective
To transform educational data into clear, interactive, and actionable insights for better analysis and decision-making.
